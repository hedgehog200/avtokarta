# АВТОКарта v1.3.0

Крупное обновление модуля ГСМ: расчёт нормы и факта приведён к методике МЧС, добавлены
надбавки, учёт стоянки/прогрева и массы груза.

## 📊 Расчёт ГСМ по методике МЧС
- Норма расхода учитывает **процентные надбавки** (зимняя, горная, кондиционер и др.).
- К работе насоса применяются только надбавки «зимняя» и «горная»; климатические и зимняя —
  **взаимоисключающие**.
- **Факт** рассчитывается по остаткам топлива (наличие перед выездом и при постановке), если они
  указаны; иначе — по норме.

## 🧮 Новые нормативы
- **Масла и спецжидкости** для ТС старше 5 лет — надбавка **+10 %** (п. 18).
- **Стоянка/прогрев** с работающим двигателем — норма в **л/час** + фактическое время (пп. 16–17).
- **Доп. расход на тонну груза/прицепа** (п. 20) с учётом фактической массы груза за рейс.
- **Мочевина AdBlue** — опциональный учёт для ТС с системой нейтрализации.

## 🗂 Справочник надбавок
- Редактируется на уровне подразделения (название, %, применение).
- Предустановленные значения — по приложению № 2 приказа ГУ МЧС.

## 🎨 Интерфейс
- Кнопки «Сохранить»/«Отмена» в форме записи всегда на виду.
- Исправлена нередактируемость справочника надбавок.
- Формы подстраиваются под размер экрана.

## ✅ Совместимость
- Формат файлов данных и выгрузки `.avto` **не изменён**: обмен со сборками v1.1.0 … v1.2.5
  работает в обе стороны. Новые поля — необязательные.
- Существующие справочники надбавок обновляются автоматически.

## 📦 Установка
- Файл: **`AVTOKarta_v1.3.0_setup.exe`**
- Требования: Windows 7 и новее, .NET Framework 4.5.2
- Для работы требуется лицензия (экран активации при первом запуске).

## 📝 Технические детали
- Версия: **1.3.0** (`AssemblyInfo.cs`, заголовок окна, установщик).
- Ядро расчёта: `CalculationService.cs`; отчёты: `ExcelExportService.cs`, `FuelReportExportService.cs`.
- Нормативная база: методика расчёта расхода ГСМ; приказ ГУ МЧС по Волгоградской области № 40 (прил. № 2).
