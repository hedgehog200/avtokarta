# АВТОКарта v1.2.5

Небольшое обновление, упрощающее установку и автообновление.

## 🔓 Установщик без пароля
- Из установщика убраны `Password=` и `Encryption=`.
- Защита обеспечивается лицензией (`license.lic`) и манифестом целостности `tamper.sig` —
  пароль установки больше не нужен.

## 🔄 Автообновление без `installer.key`
- Программа больше **не требует** файл `installer.key` для тихой автоустановки обновления.
- Пароль установщика передаётся только если файл `installer.key` присутствует; иначе установщик
  запускается без пароля.
- Обратная совместимость сохранена: если пароль вернут, достаточно положить `installer.key`.

## ✅ Совместимость
- Формат файлов данных и выгрузки `.avto` **не изменён**: обмен со сборками v1.1.0 … v1.2.4
  работает в обе стороны.
- Файлы старых версий (до v1.1.0) читаются и автоматически переводятся в текущий формат.

## 📦 Установка
- Файл: **`AVTOKarta_v1.2.5_setup.exe`**
- Требования: Windows 7 и новее, .NET Framework 4.5.2
- Для работы требуется лицензия (экран активации при первом запуске).

## 📝 Технические детали
- Версия: **1.2.5** (`AssemblyInfo.cs`, заголовок окна, установщик).
- Изменены: `AVTOKarta/Services/UpdateService.cs`, `AVTOKarta_setup.iss`, версии.
- Полные заметки к релизу: [`RELEASE_v1.2.5.md`](https://github.com/hedgehog200/avtokarta/blob/v1.2.5/RELEASE_v1.2.5.md).
