# АВТОКарта v1.2.4

Обновление посвящено скорости и надёжности обмена данными, а также надёжности релизной сборки.

## 🚀 Экспорт и импорт данных
- **Шифрование ускорено примерно в 7 раз**: PBKDF2 теперь считается через Windows CNG
  (`BCryptDeriveKeyPBKDF2`), для Windows 7 автоматически используется встроенная реализация.
  Формат файла `.avto` **не изменён**.
- **Асинхронные выгрузка и загрузка** с индикатором прогресса — интерфейс больше не «замерзает»
  на больших объёмах данных.
- Кнопки выгрузки/загрузки блокируются на время операции (защита от повторного запуска).

## 🐞 Исправления импорта
- Исправлено имя файла склада ГСМ при импорте: терялось расширение `.json`, из-за чего данные
  склада не подхватывались.
- При откате неудачного импорта удаляются созданные им файлы (в т.ч. `warehouse_*.json`),
  а не только восстанавливается снимок.
- Текст подтверждения приведён в соответствие с реальным поведением: справочники
  (части, автомобили, водители, склад) заменяются, а карточки **добавляются** к существующим.
- Версия программы в файле выгрузки берётся из сборки (раньше была прописана жёстко).

## 🔐 Защита и релиз
- Релизная сборка **всегда** обфусцируется: профиль ConfuserEx (`avtokarta.crproj`) добавлен
  в репозиторий, а конвейер `build-release.ps1` падает с явной ошибкой, если обфускация
  запрошена, но недоступна (раньше мог незаметно собраться релиз без обфускации).
- Исправлено ожидание завершения и проверка подписи в `build-release.ps1`.
- Символ защиты `PROTECTION` объявляется только в конфигурации `Release|x86`; сборка без защиты
  выполняется явным флагом `/p:NoProtection=true`.
- **Установщик больше не требует пароль** — защита обеспечивается лицензией и манифестом
  целостности `tamper.sig`.

## ✅ Совместимость
- Формат файлов данных и файла выгрузки `.avto` **не изменён**: обмен данными со сборками
  v1.1.0 … v1.2.3 работает в обе стороны.
- Файлы старых версий (до v1.1.0) читаются и автоматически переводятся в текущий формат.

## 📦 Установка
- Файл: **`AVTOKarta_v1.2.4_setup.exe`**
- Требования: Windows 7 и новее, .NET Framework 4.5.2
- Для работы требуется лицензия (экран активации при первом запуске).
