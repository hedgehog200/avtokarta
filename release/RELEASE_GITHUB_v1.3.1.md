# АВТОКарта v1.3.1

Обновление с новым разделом **«Нормативные данные»** — встроенный справочник базовых норм
расхода топлива для пожарных автомобилей и шасси МЧС.

## 📚 Справочник нормативных данных
- **181 позиция** в 4 разделах:
  - Пожарные ПА до 2008 г. (п. 15.12)
  - Пожарные ПА с 2008 г. (п. 15.12.1)
  - Пожарные ПА зарубежные с 2008 г. (п. 15.12.2)
  - Шасси — сводка (ГАЗ, ЗИЛ, Урал, КамАЗ, МАЗ, КрАЗ, ПАЗ, УАЗ, IVECO, Liebherr)
- Источник: распоряжение Минтранса России от 14.03.2008 № АМ-23-р (ред. от 30.09.2021),
  приложение II, пп. 15.12–15.12.2 «Автомобили пожарные».

## 📐 Понятные единицы измерения
Для каждой позиции — три величины с явными единицами:
- **Норма на пробег — л/100 км** (базовая линейная норма).
- **Работа со спец. агрегатом (насосом) — л/мин.**
- **Стационарный режим без нагрузки — л/мин** (прогрев / холостой ход).
- В шапке раздела — памятка «Что означают цифры» и пояснение прочерка «—».

## 🔎 Фильтр и поиск
- Фильтр по разделам справочника.
- Поиск по модели, шасси и примечанию.

## ⚡️ Подстановка норм в карточку ТС
- В форме автомобиля — выбор модели ПА / шасси из справочника.
- Норма пробега (**л/км = л/100 км ÷ 100**), расход насоса, холостой ход и тип двигателя
  заполняются автоматически.

## ✅ Совместимость
- Формат файлов данных и выгрузки `.avto` **не изменён** — полная совместимость с v1.1.0 … v1.3.0.
