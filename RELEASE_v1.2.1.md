# AVTOKarta v1.2.1

**Работа без пароля, настройка пароля в интерфейсе, 4 знака после запятой для бензиновых ГСМ, надёжное обновление.**

---

## Основные изменения

### Работа без установленного пароля
- Устранена ошибка валидации при загрузке/импорте данных без пароля: приложение больше не принудительно переходит в режим настройки, если пароль не установлен.
- Введён внутренний **DefaultPassword** (`AVTOKarta_Default_2026`), используемый при отсутствии пользовательского пароля — данные по-прежнему хранятся зашифрованными.
- Мастер первичной настройки (часть/руководитель) теперь допускает пропуск поля пароля.
- В настройках добавлена кнопка **«Установить пароль»** (видна только пока пароль не задан) — перешифровывает данные с DefaultPassword на новый пользовательский пароль.
- Кнопка **«Сменить пароль»** отображается только тогда, когда пароль уже установлен.
- Импорт данных: если пароль источника не задан, поле можно оставить пустым — данные загрузятся с DefaultPassword.

### Excel-отчёты: точность ГСМ для бензиновых автомобилей
- В отчёте ГСМ и эксплуатационной карточке значения топлива для **бензиновых** автомобилей выводятся с **4 знаками** после запятой (`0.0000`); для дизельных остаётся 3 знака (`0.000`).
- Затронуты: листы отчёта ГСМ (по видам работ, итоги по бензину, движение масла), эксплуатационная карточка (остатки, заправка, фактический расход, нормы).

### Обновление приложения (UpdateService)
- Более надёжное определение каталога обновлений: поиск записываемой папки среди нескольких кандидатов (TEMP/TMP, %LOCALAPPDATA%\Temp, профиль пользователя).
- Поиск скачанного пакета обновления по нескольким временным каталогам, если путь не найден напрямую.
