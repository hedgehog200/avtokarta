# AVTOKarta v1.1.9

**Полный редизайн интерфейса, исправление обновлений на Windows 7, условный отчёт ГСМ**

---

## Новый функционал

### Редизайн интерфейса
- Новая цветовая палитра — синий основной цвет (Primary `#2563EB`), переработаны все элементы управления
- Навигация переведена на выдвижное drawer-меню с бургером вместо тёмного sidebar
- Кнопки-стрелки на всех ComboBox (включая Drawer и FormControl) — нажатие на любую область поля открывает список
- Поддержка редактируемых ComboBox — в CardEditView текстовые ComboBox позволяют ввод с клавиатуры + выбор из списка

### Карточка учета
- **Автозаполнение пробега на начало месяца** — ChassisMileageOnFirst и EngineMileageOnFirst автоматически берутся из карточки предыдущего месяца (не только для новых карточек)
- **Приведённый пробег (ReducedMileage)** — новое расчётное поле; считается как `totalKm + totalShiftMisc × коэффициент` с округлением; отображается в шапке карточки вместо «Пробег двиг. (прив.)»
- Исправлен расчёт EngineMileageOnFirst — теперь использует приведённый пробег из записей предыдущего месяца
- Поле ChassisMileageOnFirst теперь только для чтения (серый фон, редактирование невозможно)

### Отчёт ГСМ
- Условный вывод секций «МиС», «специальные масла и жидкости», «пластичные смазки» — печатаются только при наличии данных
- Убраны пустые строки «СЖ» и «ТС-1 (керосин)» при отсутствии данных

---

## Исправления

### Обновления
- Исправлена ошибка SSL/TLS при проверке обновлений на Windows 7: TLS 1.3/1.1 с fallback, перестройка цепочки сертификатов с X509VerificationFlags.AllFlags, пропуск PartialChain/UntrustedRoot для устаревших корневых сертификатов

### Интерфейс
- Редактируемые ComboBox больше не теряют выбранных значений водителя и описания работы
- Все числа в UI и Excel приведены к формату до тысячных (F3 / 0.000)

---

## Оптимизации

- Кэширование ключей шифрования — PBKDF2 выполняется 1 раз вместо 3 на операцию
- Асинхронные сохранения — SaveSquadsAsync, SaveVehiclesAsync, SaveCardAsync не блокируют UI
- Загрузка данных в фоне — окно отображается сразу, данные загружаются асинхронно
- Отложенная миграция — шифрование HMAC выполняется после показа данных
- Маркер миграции — повторная миграция пропускается при следующих запусках
