# AVTOKarta v1.1.7

**Исправление загрузки данных в Excel и новый функционал**

---

## Исправления

### Эксплуатационная карточка
- В строках разбивки по типам выездов (Учебный выезд, Пожар, Прочий пробег, Ложно) колонка **«Расход ГСМ л.»** теперь отображает расход топлива в литрах вместо километров пробега
- Добавлен метод `CalculateFuelByTripType()` в `CalculationService` — корректно суммирует `NormConsumption` по типам выездов

### Отчёт движения ГСМ
- Строка **«МиС Всего»** (масла, смазки): наличие на начало периода и расход теперь вычисляются из норм транспортного средства вместо всегда нулевых значений
- Строка **«Специальные масла и жидкости»**: расход теперь отображает реальные данные
- Переменные `TotalMotorOil`, `TotalTransOil`, `TotalSpecLiquid`, `TotalPlasticLub` теперь вычисляются по формуле `totalConsumption / 100 × normPer100L` для каждого автомобиля

### Метаданные экспорта
- Версия приложения в экспортируемых `.avto` файлах обновлена с `1.0` до `1.1.7`

## Новый функционал

### Справочник водителей
- Новая модель `Driver` (`Models/Driver.cs`)
- Новый `DriverListViewModel` — логика списка, добавления, редактирования и удаления водителей
- Новый экран `DriverListView` — полный интерфейс управления водителями

### Склад
- `WarehouseViewModel` — добавлен метод `SyncFromCards()`, автоматически синхронизирующий расходы масел из дневниковых записей карточек
- `WarehouseItem` — добавлены новые свойства для привязки данных

### Транспортные средства
- `Vehicle` — добавлены новые свойства для расширенной информации
- `VehicleViewModel` — добавлены свойства для привязки к интерфейсу

### Вспомогательные классы
- `PhoneHelper` (`Helpers/PhoneHelper.cs`) — форматирование и валидация телефонных номеров
