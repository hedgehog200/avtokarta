# АВТОКарта v1.2.3

**Дата:** 11.09.2026

---

## Что нового

### Защита от вмешательства (целостность приложения)
- Подписанный манифест целостности `tamper.sig`: каждый исполняемый файл и библиотека приложения (включая сторонние DLL: ClosedXML, OpenXml, HandyControl и др.) подписаны RSA-2048
- Проверка целостности при каждом запуске: изменённый или «подброшенный» файл обнаруживается, доступ к расширенным функциям ограничивается
- Реагирование на работу под отладчиком, контроль точек входа (AntiDebug)

### Лицензионная система
- Лицензии по коду ПК: разовые и на срок, с ограничением числа станций
- Экран лицензии при запуске: ввод ключа, получение кода ПК, статус и срок действия
- Проверка подписи лицензии при старте; при отсутствии/недействительности — режим с ограниченными функциями
- **LicGen** — приложение для выпуска лицензий:
  - GUI: база выданных лицензий и кодов ПК, выписка лицензии в несколько кликов, создание ключевой пары
  - CLI сохранён для массовой выдачи и конвейера сборки релиза

### Экспорт данных
- Предупреждение при выгрузке Excel-файла **без пароля** — явное подтверждение, что файл не будет защищён

### Надёжность шифрования данных
- Постоянная энтропия DPAPI для ключей шифрования: ранее сохранённые данные (squads, vehicles, cards и др.) гарантированно расшифровываются после перезапуска
- Корректная загрузка установочного пароля

### Обфускация релиза
- Конвейер сборки релиза `build-release.ps1`: MSBuild → ConfuserEx (control flow / anti-tamper / anti-debug) → подпись манифеста → контрольная проверка
- Версия сборки: **1.2.3**

---

## Исправления

- GUI-выпуск лицензии в LicGen завершался ошибкой «файл не найден»: файл проверялся до записи. Теперь лицензия записывается и после этого проверяется по подписи

## Технические детали

### Версия (обновлено везде)
- `AssemblyInfo.cs` — `AssemblyVersion` / `AssemblyFileVersion`
- `MainWindow.xaml` — заголовок окна
- `DataTransferService.cs` — `AppVersion`
- `AVTOKarta_setup.iss` — `MyAppVersion` / `VersionInfoVersion`

### Установщик
- Inno Setup: `AVTOKarta_setup.iss` (установка с паролем, шифрование)
- Имя выходного файла: `AVTOKarta_v1.2.3_setup.exe`
- В состав входят все библиотеки приложения и манифест `tamper.sig`

---

## Сборка

1. Запустить `build-release.ps1`: MSBuild (Release) → ConfuserEx → `LicGen --sig-issue` → `LicGen --sig-check`
2. Собрать установщик: `AVTOKarta_setup.iss` → `Output\AVTOKarta_v1.2.3_setup.exe`
