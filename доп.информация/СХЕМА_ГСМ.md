## 3. Формулы

### 3.1. За выезд (путевой лист)

Обозначения: `H` — нормы; `S` — пробег, км; `t` — время, мин; `D` — суммарная надбавка/снижение, %.

```
Qпробег  = H_пробег(л/км) · S · (1 + D_пробег/100)
Qнасос   = H_насос(л/мин) · t_насос · (1 + D_насос/100)
Qхолост  = H_холост(л/мин) · t_холост
Qсмена   = H_смена(л/мин) · t_смена
Qпрочие  = H_прочие(л/мин) · t_прочие

Qнорм  = Qпробег + Qнасос + Qхолост + Qсмена + Qпрочие      // «Положено по норме»
Qфакт  = НаличиеПередВыездом + Получено − НаличиеПриПостановкеНаСтоянку   // «Израсходовано»

Экономия   = max(0, Qнорм − Qфакт)
Перерасход = max(0, Qфакт − Qнорм)
```

### 3.2. За месяц (карточка / книга учёта)

```
Qфакт(мес) = Σ Qфакт(выезд) = НаличиеНаНачало + Σ Получено − НаличиеНаКонец
Qнорм(мес) = Σ Qнорм(выезд)
Экономия(мес) = max(0, Qнорм(мес) − Qфакт(мес))
Перерасход(мес) = max(0, Qфакт(мес) − Qнорм(мес))
```

**Нормы-«часовые» (не проценты, а л/час стоянки):**
- п. 16 — простои под погрузкой/разгрузкой с работающим двигателем (где запрещено глушить): **+10 %** за час простоя;
- п. 17 — зимой/в холодное время (среднесуточная < +5 °C) на стоянках при пуске/прогреве (если нет независимых отопителей): **нормативный расход за 1 час стоянки с работающим двигателем**.

**Дополнительный линейный расход:**
- п. 20 — при движении с грузом/прицепом: **+2 л/100 км** на каждую тонну груза (бензин); **+1,3 л/100 км** (дизель).

**Особое правило (п. 21):** **при работе оборудования применяются только надбавки на работу в зимнее время и в горной местности.**
→ к работе насоса/спец. агрегата применяются **только** надбавки «Зимняя» и «Горная местность»; остальные — только к пробегу.

**Правило суммирования:** при нескольких надбавках проценты **суммируются** (снижения — вычитаются).

**Зимняя надбавка** — авто-применение по дате записи (период задаётся на части, по умолчанию **15.11–15.03**), с возможностью ручной правки.

**Применение (подтверждено):** к **пробегу** — все надбавки; к **работе насоса** — только «Зимняя» и «Горная»; к холостому — **нет**.

## 9. Решения (зафиксировано)

- Единицы нормы на пробег: **л/км** (как в ПО). Без миграции.
- Надбавки: **к пробегу — все**; **к работе насоса — только «Зимняя» и «Горная» (п. 21)**; **к холостому — нет**.
- Поле «норма на пробег с насосом» (`ConsumptionPerKmWithPump`) — **убираем из формы ТС** (насос нормируется в л/мин). Поле в модели оставить (совместимость), но не использовать.
- Надбавки — **редактируемый справочник на уровне части** с пресетами по прил. № 2 приказа ГУ МЧС (Волгоград, приказ № 40 от 22.01.2024); зимний период по умолчанию **15.11–15.03**.

### Остаётся уточнить
- Нужен ли учёт **нескольких сортов** ГСМ в одном путевом листе (Прил. № 35), или один сорт на запись?
- Нужны ли **нормы-«часовые»** (пп. 16–17: стоянка/прогрев с работающим двигателем) как отдельные поля (л/час), или достаточно «холостого хода» (л/мин)?
- Нужен ли **доп. линейный расход по массе груза/прицепа** (п. 20: +2 л/100 км бензин, +1,3 л/100 км дизель за тонну)?
